# Pratheesh Physiotherapy

A React portfolio prototype for Pratheesh. The current [Vercel site](https://portfolio-pratheesh-kappa.vercel.app/) is public but contains clearly marked placeholders. Pratheesh's biography, qualifications, services, case material, portrait, contact details, and clinic location need approval before the site is presented as a finished professional portfolio.

The source is hosted in the [GitHub repository](https://github.com/yadukrishnagiri/portfolio-pratheesh). Pushing to `main` triggers a production deployment on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Run `npm run build` to create a production bundle in `dist/`.

## Content to replace

- The portrait frame in the hero is intentionally empty.
- Service and approach descriptions are illustrative and visibly labeled as such.
- The about section awaits a verified biography and credentials.
- The work section awaits approved case studies or resources.
- Booking, WhatsApp, email, and map locations are displayed as unavailable until real destinations are provided. They do not link to invented details.

The design composition reference is saved at `.impeccable/mocks/composition.png`. It is not used as page imagery.
